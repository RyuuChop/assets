Put the converted GLB files of the "New Chess" set in THIS folder, with exactly these names:

  pawn.glb   rook.glb   knight.glb   bishop.glb   queen.glb   king.glb

The set then shows up automatically as "New Chess" in Theme & Board Studio (3D Model Set).
See tools/README.md for how to turn the STL files into these GLB files.
